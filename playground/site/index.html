Why MiniPty GitHub

MiniPty lets a .NET app run a shell or a CLI tool in a PTY, a terminal without a window. The app types keys and reads the screen, as a person does. Each scene replays a recorded session and shows each call to MiniPty.

    Why MiniPty
    
    
    
      
    
        
    Knows when a program asks for a password
    
        
    On Linux and macOS, InputMode shows when sudo or ssh turns off echo for a password. An agent or a test script can stop there, ask a person, and keep the password out of its logs.
    
        
    Play the password scene · Password prompts
    
      
    
      
    
        
    Gets a command's result in one call
    
        
    CompleteAsync returns the output and the exit code. MiniPty.Capture also gives the time of each chunk. MaxOutputBytes ends a command that prints too much.
    
        
    Run a command for its result
    
      
    
      
    
        
    Browser terminals that survive a restart
    
        
    PtyWebSocketBridge.RunAsync connects a shell to xterm.js in one call. When the shells run in a PTY host of their own, a web server restart does not end them. The page reconnects and gets the output it missed.
    
        
    Web terminal · Separate PTY host
    
      
    
      
    
        
    Thousands of shells in one process
    
        
    A session that waits for output holds no thread. Reads, writes, and waits allocate nothing after the first call. So a web server or an agent host can keep thousands of shells open.
    
        
    Performance
    
      
    
    
    
  
    

  
    
    
    Use MiniPty
    
    
    
      
    
        
    Add it to your app
    
        
    Start a shell or a CLI in a real PTY, type into it, and read its screen. MiniPty runs on .NET 10 on Windows, Linux, and macOS, and works with NativeAOT.
    
        
    dotnet add package MiniPty
    
        
    Quick start · NuGet
    
      
    
      
    
        
    Build a terminal or an agent tool
    
        
    Samples show a browser terminal with xterm.js, a VS Code terminal, and a desktop terminal window. Other samples run commands and drive programs, as an AI agent does.

    Record your CLI for a README or a post
    
        
    scenetake runs a YAML scenario and records it as an asciinema .cast, an animated SVG, or an MP4. Its pty: true steps run through MiniPty. It also comes as a .NET tool and as a binary.
    
        
    npm install -g scenetake
